# Сессии для Claude Code

[English](README.md) | Русский

Все сессии Claude Code на машине на одной странице в браузере: дерево хост → проект → сессия → форки, карточка со всем, что известно о сессии, её стоимость и срок, когда Claude Code её удалит, и поиск по тому, что было написано.

Это мод для [Claude Hub](https://github.com/jabenb/claude-webhub): страница живёт в хабе рядом со страницами других модов, в группе **Вся машина**.

## Что умеет

- **Дерево.** Сессии сгруппированы по проектам (папке, где они запускались); форк или продолженная сессия стоит под той, от которой пошла, на любой глубине. Идущие сейчас сессии отмечены; в строке видны ветка, последняя активность, стоимость, число сообщений и форков.
- **Карточка.** Название, первый и последний промпт, ветки, модели, effort, режим разрешений, где запущена (приложение или CLI), версия; время; токены по видам и по моделям и стоимость (≈, по токенам и ценам API); инструменты, изменённые файлы, добавленные и удалённые строки, сабагенты; родитель и место ответвления, дочерние форки и стоимость всего дерева форков; кнопка, которая копирует `claude --resume <id>`.
- **Срок жизни.** Когда Claude Code удалит файл переписки (`cleanupPeriodDays` в `~/.claude/settings.json`, по умолчанию 30 дней от последнего изменения), значок у сессий, которые удалятся в течение недели, и фильтр по ним.
- **Поиск.** Мгновенный поиск по названиям, промптам, веткам, проектам и файлам, с `host:`, `project:`, `branch:`, `after:`, `before:`, `model:` и `"точной фразой"`. Поиск по тексту всех переписок (Enter с «искать в тексте»), по желанию и по выводу инструментов. Поиск по смыслу (выключен по умолчанию): один вызов модели, тратит токены, модель задаётся в настройках.
- **Переписка.** Сообщения сессии, вызовы инструментов с их выводом, что форк взял у родителя и где от сессии ответвились её форки.

Мод не тратит токены, кроме поиска по смыслу, когда вы его включаете.

## Что нужно

- [Claude Hub](https://github.com/jabenb/claude-webhub) **0.2.0 или новее** (страница всей машины, `scope: 'global'`).
- `python3` на машине, где работает Claude Code: мод читает файлы переписок небольшим скриптом на стандартной библиотеке.

## Установка

```bash
claude plugin install webhub --marketplace jabenb/claude-webhub --scope user
claude plugin install sessions --marketplace jabenb/claude-sessions --scope user
```

Ставьте оба с одним scope: страница принадлежит всей машине, поэтому естественный вариант — `user`.

## Как пользоваться

Команда `/sessions` в любой сессии покажет адрес страницы; или откройте хаб (`/hub`) и выберите **Сессии** в группе **Вся машина**. По SSH пробросьте порт хаба, как описано в README хаба.

Страницу наполняют сессии, в которых стоит мод: одна из них раз в 15 секунд читает файлы переписок (только то, что изменилось), а на поиск со страницы отвечает та, где вы писали последней. Если ни одна сессия Claude Code не запущена, страница показывает последние данные и пишет, что они не обновляются.

### Настройки

| Настройка | По умолчанию | Что это |
|---|---|---|
| `semanticModel` | `haiku` | Модель для поиска по смыслу: псевдоним (`haiku`, `sonnet`, `opus`) или полный id модели. |

## Где хранятся данные

Кеш индекса лежит в `~/.claude/mods-data/sessions/` (в `$CLAUDE_CONFIG_DIR`, если задан). Мод только читает `~/.claude/projects` и `~/.claude/sessions` и никогда не меняет и не удаляет переписки.
